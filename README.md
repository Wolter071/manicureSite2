# Сайт мастера маникюра: этап 1

Готово на этом этапе: главная, палитра, услуги из базы, онлайн-запись с проверкой свободного времени,
защита от двойного бронирования, уведомления мастеру в Telegram с кнопками «Подтвердить» и «Отклонить».
Админ-панели, отзывов, портфолио, английской версии и SEO пока нет: это следующие этапы.

## Что нужно установить на ПК
1. Node.js 20 или новее (https://nodejs.org, версия LTS).
2. Docker Desktop (https://www.docker.com/products/docker-desktop) для базы PostgreSQL.
   Без Docker можно поставить PostgreSQL 16 обычным установщиком и поменять DATABASE_URL в .env.local.

## Создайте Telegram-бота
1. В Telegram откройте @BotFather, отправьте /newbot, придумайте имя.
2. Скопируйте выданный токен. Он секретный: никому не показывайте и не публикуйте.

## Запуск (в папке проекта, в терминале)
```
npm install
copy .env.example .env.local        (macOS/Linux: cp .env.example .env.local)
```
Откройте `.env.local` и вставьте токен в `TELEGRAM_BOT_TOKEN`.
```
docker compose up -d                # запускает базу данных
npm run migrate                     # создаёт таблицы, демо-услуги и расписание
npm run build
npm run start                       # сайт: http://localhost:3000
```
Во втором окне терминала:
```
npm run bot
```
Напишите вашему боту /start. Он ответит вашим chat id. Вставьте его в `MASTER_CHAT_ID`
в `.env.local`, затем остановите (Ctrl+C) и заново запустите `npm run start` и `npm run bot`.

## Проверка
1. Откройте http://localhost:3000, выберите цвет, услугу, дату и время, отправьте заявку.
2. В Telegram придёт сообщение с кнопками. «Подтвердить» или «Отклонить» меняет статус в базе.
3. Отклонённая заявка освобождает время. Занятое время нельзя забронировать повторно.

С телефона в той же Wi-Fi сети сайт открывается по адресу http://IP-ВАШЕГО-ПК:3000
(Windows может спросить разрешение для Node.js в брандмауэре).

## Как это устроено
- Расписание (рабочие дни, часы, перерыв, шаг, «не раньше чем за N часов») лежит в таблице `settings`, ключ `schedule`.
  Пока админ-панели нет, его можно менять в базе. Услуги лежат в таблице `services`.
- Двойное бронирование исключено ограничением в самой базе (`bookings_no_overlap`), а не только проверкой в коде.
- Защита от спама: не более 5 заявок за 10 минут с одного IP, скрытое поле-ловушка,
  не более 2 активных записей на один телефон, проверка данных на сервере.
- Токен бота и пароль базы нужны только серверу (`.env.local`, файл не попадает в git).
- Бот работает через long polling, поэтому публичный адрес для него не нужен.

## Ограничения этапа 1
- Клиент не получает уведомление о решении мастера (нужна привязка клиента к боту: этап 2).
- Отмены и переносы пока делаются вручную в базе. Напоминания за 24 и 2 часа не реализованы.
- Главная пока статический файл `public/site.html`; для SEO и английской версии её нужно перенести в React.
- Пароль базы в docker-compose.yml демонстрационный: поменяйте его, прежде чем открывать сайт в интернет.
- Страницы «Политика конфиденциальности», «Отзывы», «FAQ» и «Контакты» ещё не созданы.
